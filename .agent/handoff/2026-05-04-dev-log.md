### SlideCanvas.vue 运行时崩溃修复（2026-05-04 续）

#### 错误现象
- 控制台报错：`TypeError: Cannot read properties of null (reading 'dynamicGuidance')`
- 触发位置：`SlideCanvas.vue:191`，`textCueClass()` 函数
- 根因：`isActivePoint()` 在 `activeCue === null` 时返回 `true`
  - `label = ""`（空字符串，来自 `|| ""` 兜底）
  - `point.includes("")` 永远返回 `true`（JS 特性：空字符串是任意字符串的子串）
  - 导致后续访问 `props.activeCue.dynamicGuidance` 时崩溃

#### 修复内容（SlideCanvas.vue）
1. **`isActivePoint()`**：添加 `if (!props.activeCue) return false` 和 `label.trim()` 空串检查
2. **`pointCueClass()`**：`props.activeCue.dynamicGuidance` → `props.activeCue?.dynamicGuidance`
3. **`textCueClass()`**：同上，添加可选链
4. **`codeFieldCueClass()`**：同上，添加可选链

#### 验证
- `npx vite build` 编译通过，0 错误
- Git 提交：`a58ecbf` - Fix: SlideCanvas null-safety

#### 经验教训
- JS/TS 中 `String.includes("")` 永远返回 `true`，做子串匹配前必须检查空串
- 所有访问 `props.activeCue.xxx` 的地方都需要 `?.` 防护（Vue computed 中可能访问到 null）
