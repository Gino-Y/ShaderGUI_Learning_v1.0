## 五、待修复的问题

### 1. `design_mcp.py` 缺少 `_infer_typography()` 方法
**位置**: 第 124 行  
**修复方案**: 添加 `_infer_typography()` 静态方法

示例实现:
```python
@staticmethod
def _infer_typography(visual_comp: dict) -> dict:
    """从 visualComposition 推断排版规范"""
    default_typo = {
        "title": "text-3xl font-bold",
        "subtitle": "text-lg text-slate-400",
        "body": "text-base leading-relaxed",
        "caption": "text-sm text-slate-400",
    }
    if not visual_comp:
        return default_typo
    
    # 根据 visualComposition 中的线索调整
    # 例如：如果有 "largeTitle": true，则增大标题字号
    if visual_comp.get("largeTitle"):
        default_typo["title"] = "text-4xl font-bold"
    
    return default_typo
```
