# 2026-05-05 工作记录

## 表演动画消失 — 完整排查与修复记录

### 问题现象
用户执行完整 MVP 流程后，表演动画（FlowPathDemo）全部消失。

### 根因（两层）
1. **字段名不一致**：`storyboard_mcp.py` 的 `build_performance_for_cue()` 返回字典用 `performanceType`/`demoType`，但 Vue 组件消费的是 `type`/`demo`，导致 Vue 读到 `undefined`
2. **MVP cleanup 删除了产物但未正确重新生成**：cleanup 删除了 `CourseApp/src/data/`，但重新生成时合约字段名还是错的

### 修复过程（有曲折）

#### 第一次（错误）
- 直接修改了 `.agent/mcp_servers/storyboard_mcp.py`、`.agent/templates/` 等源头文件 ✅
- **但还直接修改了 `CourseApp/src/components/` 产物文件** ❌（违反规则）
- 提交 `0736b00`（正确），又提交 `8365583`（直接改产物，错误）

#### 用户纠正
> "禁止修改任何产物文件，只能通过修改MCP节点，删除产物，重新生成的方式修改"

#### 第二次（正确）
1. **添加规则**：在 `.agent/rules.md` "对齐约束" 部分添加：
   ```
   [NO_DIRECT_EDIT_OUTPUT] **禁止直接修改产物文件**；只能通过修改 `.agent/` 中的 MCP 节点或模板 → 删除产物 → 重新生成的方式修改。
   ```
2. **撤回错误提交**：`git revert 8365583`
3. **删除产物**：`rm CourseApp/src/components/SlideCanvas.vue CourseApp/src/components/PerformanceLayer.vue`
4. **从模板重新生成**：`cp .agent/templates/course-app/src/components/*.vue CourseApp/src/components/`
5. **构建验证**：`npm run build` ✅
6. **提交**：`a53e225` — "fix(vue): 按正确流程重新生成Vue产物文件"
