# 2026-05-05 工作日志

## 关键修复：节点漂移（Node Drift）问题

### 问题描述
每次重新运行 MVP 生成时，CourseApp 中的自定义修改都会丢失。这是因为 MCP 服务器的生成逻辑存在缺陷。

### 根本原因
1. `mvp-execution-scope.json` 中的 `clean.allow` 列表包含 `"CourseApp/src"`
2. 这导致整个 `src` 目录被删除
3. 然后 `_copy_template_tree()` 重新复制模板文件
4. 尽管 `_copy_template_tree()` 有"不覆盖已存在文件"的逻辑，但因为文件已被删除，所以总是会重新复制

### 修复方案
1. **修正 `mvp_mcp.py`**：
   - 添加缺失的 `_ensure_audio()` 方法
   - 该方法只检查音频文件是否存在，不生成音频（由 flow engine 处理）

2. **修正 `mvp-execution-scope.json`**：
   - 从 `clean.allow` 列表中移除 `"CourseApp/src"`
   - 这样 `src` 目录不会被删除
   - `_copy_template_tree()` 的"跳过已存在文件"逻辑现在正常工作

3. **修正 `storyboard_mcp.py`**（之前完成）：
   - 修正 `build_performance_specs_for_slide()` 中的语义规则
   - 使 `_build_flow_path_payload()` 动态化（根据内容推断流程节点）

4. **修正 `design_mcp.py`**（之前完成）：
   - 使 `generate_visual_refs()` 优先使用 storyboard 数据
   - 根据 `visualComposition` 推导 `layoutSpec`、`colorScheme` 和 `componentList`

### 验证结果
✅ 重新运行 MVP 生成后，`CoursePlayer.vue` 的修改被保留
✅ 节点漂移问题已修复
