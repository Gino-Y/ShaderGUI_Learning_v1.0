# 2026-05-04 UTF-8 Encoding Rule

## Feedback

User required that all text encoding in the project be forcibly standardized to UTF-8 and written into the project rules.

## Rule Update

Updated `.agent/rules.md` with `Text Encoding Standard Rule`.

## New Standard

- All project text files must use UTF-8.
- New text files must be created as UTF-8.
- Any touched legacy text file that shows encoding problems must be normalized to UTF-8.
- `.agent/` assets are included in the mandatory UTF-8 scope.
- Generated text artifacts are also included.
- Encoding violations are delivery blockers until corrected.
